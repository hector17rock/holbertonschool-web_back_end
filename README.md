## 🔧 Setup & Installation

### Prerequisites

```bash
# System requirements
Python 3.8+
Node.js 20+
npm 10+
MongoDB 4.4+
```

### Quick Start

```bash
# Clone the repository
git clone https://github.com/hector17rock/holbertonschool-web_back_end.git
cd holbertonschool-web_back_end

# For JavaScript projects
cd ES6_basic
npm install
npm run dev 0-main.js

# For Python projects
cd ../python_variable_annotations
python3 0-main.py

# For Node.js projects
cd ../Node_JS_basic
npm install
npm run dev
```

### Development Environment Setup

```bash
# Install development tools
npm install -g eslint babel-cli
pip install mypy pycodestyle

# Run code quality checks
npm run lint          # For JavaScript projects
mypy *.py            # For Python type checking
pycodestyle *.py     # For Python style checking
```
